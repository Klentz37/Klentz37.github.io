GAME 1 - RECORDED CLIPS
=======================

Put Game 1's clips in this folder. Format: MP4 (H.264 + audio), 1280x720 or smaller.
Names (lower case):

  menu.mp4             Game's main menu - loops until the visitor presses A

  state_r1.mp4         Countdown before throw 1 / 2 / 3 (throwing opens when it ends)
  state_r2.mp4
  state_r3.mp4

  win_r1_short.mp4  win_r1_med.mp4  win_r1_high.mp4     Win on throw 1
  win_r2_short.mp4  win_r2_med.mp4  win_r2_high.mp4     Win on throw 2
  win_r3_short.mp4  win_r3_med.mp4  win_r3_high.mp4     Win on throw 3 (always wins)

  lose_r1_short.mp4 lose_r1_med.mp4 lose_r1_high.mp4    Lose on throw 1 -> throw 2
  lose_r2_short.mp4 lose_r2_med.mp4 lose_r2_high.mp4    Lose on throw 2 -> throw 3

short / med / high = how long A (left mouse) is held before release in the room.
If menu.mp4 isn't here, Game 1 uses the built-in graphics version instead.
